# Online Therapy Booking System

A complete platform for booking online therapy sessions with licensed professionals.

![Mindful Therapy Logo](assets/logo.jpg)

## Features

- User registration and authentication
- Browse licensed therapists with specialties
- Book therapy sessions with available time slots
- Manage upcoming and past sessions
- Contact form for support inquiries
- Admin dashboard for managing users and therapists
- Responsive design for all devices

## Technologies Used

### Frontend
- HTML5, CSS3, JavaScript
- Responsive design with Flexbox/Grid

### Backend
- Node.js
- Express.js
- MongoDB (Database)
- Mongoose (ODM)
- JWT (Authentication)

### Development Tools
- NPM (Package Manager)
- Git (Version Control)

### Prerequisites
